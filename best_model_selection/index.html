Deployment Guide

1. System Setup

Requirements:

  • Python 3.8+
  • NVIDIA GPU (RTX4070 or RTX4080 recommended)
  • CUDA 11.8+
  • cuDNN 8.x

Install Dependencies

Verify Installation

python -c "import torch; print(f'PyTorch: {torch.__version__}')"
python -c "import torch; print(f'CUDA Available: {torch.cuda.is_available()}')"

2. Load Quantized Model

from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig
import torch

# Configure INT8 quantization
quant_config = BitsAndBytesConfig(load_in_8bit=True)

# Load model (GPT-2 recommended for speed)
model = AutoModelForCausalLM.from_pretrained(
    "gpt2",
    quantization_config=quant_config,
    device_map="auto",
    torch_dtype=torch.float16,
)

# Load tokenizer
tokenizer = AutoTokenizer.from_pretrained("gpt2")
if tokenizer.pad_token is None:
    tokenizer.pad_token = tokenizer.eos_token

print("Model loaded successfully!")
print(f"Model device: {model.device}")

3. Basic Inference

def generate_text(prompt, max_tokens=256):
    inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
    
    with torch.no_grad():
        output = model.generate(
            **inputs,
            max_new_tokens=max_tokens,
            do_sample=False,  # Greedy decoding
            temperature=1.0,
        )
    
    text = tokenizer.decode(output[0], skip_special_tokens=True)
    return text

# Example usage
prompt = "Once upon a time"
response = generate_text(prompt)
print(response)

4. FastAPI Server

Create a simple production API server:

from fastapi import FastAPI
from pydantic import BaseModel
import uvicorn

app = FastAPI()

class GenerateRequest(BaseModel):
    prompt: str
    max_tokens: int = 256

@app.post("/generate")
def generate(request: GenerateRequest):
    output = generate_text(request.prompt, request.max_tokens)
    return {"output": output}

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)

Batch Processing for Better Throughput

def generate_batch(prompts, batch_size=4):
    results = []
    for i in range(0, len(prompts), batch_size):
        batch = prompts[i:i+batch_size]
        inputs = tokenizer(batch, return_tensors="pt", padding=True).to(model.device)
        
        with torch.no_grad():
            outputs = model.generate(**inputs, max_new_tokens=256)
        
        texts = tokenizer.batch_decode(outputs, skip_special_tokens=True)
        results.extend(texts)
    
    return results

Normalization Method

All metrics normalized to [0, 1] using min-max scaling:

norm_value = (value - min) / (max - min)

This ensures fair comparison across different scales without assuming ideal values.

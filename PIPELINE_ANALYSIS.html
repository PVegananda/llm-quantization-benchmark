Multi-Criteria Model Selection

Notebook 05 applies an objective scoring algorithm using 6 weighted criteria:

Criterion Weight Rationale
Throughput (tokens/sec) 25% Primary efficiency metric
ROUGE-1 20% Word-level semantic recall
BLEU 15% Phrase-level accuracy
ROUGE-L 15% Structural coherence
VRAM Efficiency 15% Memory footprint
GPU Residency 10% No CPU offloading needed

Methodology: Min-max normalization [0,1] across all configurations, then weighted sum to produce final score (0-1 scale).

Recommendation for Use Cases:

Use GPT-2 INT8 RTX4080 for:

  • Real-time inference applications
  • Resource-constrained environments (edge, mobile, IoT)
  • Latency-sensitive tasks (less than 100ms requirement)
  • Cost-optimized cloud deployments
  • Batch processing with high throughput needs

Consider FP16 if:

  • High-quality output is critical (academic writing, technical documentation)
  • Complex reasoning or multi-step inference needed
  • Quality degradation is not acceptable
